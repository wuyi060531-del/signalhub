三步导入

下载JSON导入模板（明确合成，不计真实覆盖）。替换为完整真实官方数据并确认保存权限后才将is_demo改为false；未知字段保留null。

  1. 正常打开官方具体职位，保留稳定编号、官方链接、职位名、实际企业、地点，以及完整职责和要求。受限页面只用你有权保存的文本或授权文件。
  2. 在“信息导入”粘贴JD。明确招聘类型、到岗时间才填写；未知学历、届别、薪资、时间保持空。人工核验时间需含时区，说明应写明核对的入口、职位编号、在列或关闭证据和条件。单条导入可选择“仍在列 / 关闭 / 待核验”，仅JD可见不能等同仍在列；最近在列标签仅保留7日，之后恢复历史状态未知。只粘贴链接不能声明已核验。文件支持UTF-8 CSV / JSON（2MB、1000行），未授权文件不要导入。
  3. 等解析任务成功，检查原文与资格；在档案设置方向、招聘类型、开始窗口和可实习时长，刷新匹配。重复导入使用同一来源和稳定编号；企业本土/外企分类另需官方集团证据，不按手填企业类型自动认定。

人工核验时间是导入者声明，系统不会联网替你确认。原文首次存档、来源最近成功采集与岗位最近验证是不同事实。候选仍需投递前打开官方入口确认在招；系统不自动投递。

如果未来取得企业书面许可、公开文档化API或正式授权导出文件，再按限定域名、访问频率和许可范围接入。
